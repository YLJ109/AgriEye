# 部署教程

## 环境要求

- Python 3.10+
- Node.js 18+
- npm 9+
- 无需 GPU，全程 CPU 推理
- 无需云服务器，本地电脑即可

## 一、后端部署

### 1.1 安装依赖

```bash
cd backend
pip install -r requirements.txt
```

> 首次安装 torch 较大（约 200MB），请耐心等待。如安装慢可配置国内镜像：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 1.2 构建 RAG 知识库

```bash
python knowledge/build_vector_db.py
```

该脚本将 `knowledge/*.json` 转为 FAISS 向量索引。首次运行会下载句向量嵌入模型（约 120MB），后续离线可用。

### 1.3 启动后端

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

- API 文档：http://localhost:8000/docs
- 健康检查：http://localhost:8000/api/system/health

### 1.4（可选）训练并部署模型

```bash
cd ../algorithm
pip install -r requirements.txt
python train.py                 # 一键：数据集→训练→量化→部署
```

训练完成后模型自动导出到 `backend/data/models/yolov8_lite_agri.onnx`，重启后端即可加载。

> **未训练模型时**，系统使用启发式识别回退（基于颜色/纹理特征），保证开箱即可演示完整流程。

## 二、前端部署

### 2.1 安装依赖

```bash
cd frontend
npm install
```

### 2.2 开发模式

```bash
npm run dev
```

访问 http://localhost:5173 ，已配置代理转发 `/api` 到后端 8000 端口。

### 2.3 生产构建

```bash
npm run build      # 输出到 dist/
npm run preview    # 本地预览生产包
```

构建产物为纯静态文件，可部署到任意静态服务器（Nginx、对象存储等）。

## 三、一键启动（Windows）

项目根目录提供 `start.bat`：

```bash
# 在项目根目录执行
start.bat
```

将同时启动后端（8000）和前端（5173）。

## 五、离线部署说明

### 完全离线运行条件
1. 后端依赖已安装（`pip install` 完成）
2. RAG 知识库已构建（`build_vector_db.py` 执行过）
3. 嵌入模型已缓存（首次构建后自动缓存到用户目录）
4. 模型已训练或使用启发式回退

满足以上条件后，断网仍可：
- 图片识别（CPU 推理）
- RAG 问答（本地 FAISS 检索）
- 历史记录、农事日历（本地 SQLite）

### 移动端适配
前端响应式布局，手机浏览器访问 http://服务器IP:5173 即可使用，无需安装 App。

## 六、常见问题

### Q1: 启动后端报 ModuleNotFoundError
确保在 `backend` 目录执行，且已 `pip install -r requirements.txt`。

### Q2: 识别返回但置信度低
未训练模型时使用启发式回退，置信度为基础值。运行 `algorithm/train.py` 训练真实模型后精度提升。

### Q3: RAG 问答返回"暂未检索到"
先执行 `python knowledge/build_vector_db.py` 构建向量索引。

### Q4: 前端接口 404
确认后端已启动在 8000 端口，前端 `vite.config.js` 代理配置正确。

### Q5: torch 安装失败
本项目强制 CPU 版本，安装命令：
`pip install torch==2.4.1 torchvision==0.19.1 --index-url https://download.pytorch.org/whl/cpu`
