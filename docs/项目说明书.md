# 项目说明书

## 一、项目背景

我国是农业大国，农作物病虫害每年造成巨大经济损失。传统农业 AI 识别系统存在三大痛点：

1. **识别能力单一**：市面产品多只能识别单一病害，无法区分病害、虫害、缺素、药害这四类田间肉眼极易混淆的问题，农户即便"识别"了也常常误判误治。
2. **数据依赖重**：主流模型需上万标注样本，标注成本高、长尾病害覆盖差，野外遮挡、逆光、复杂田地环境下识别精度骤降。
3. **农村落地难**：依赖云端推理，农村偏远地区弱网/无网环境下无法使用，且只"识别"不"开方"，缺乏落地服务价值。

本项目针对上述痛点，构建一套**基于多模态小样本的农作物病虫害 + 缺肥智能诊断与农事 AI 顾问系统**，实现手机拍照离线识别、自动溯源减产原因、智能生成绿色农事方案，打造轻量化普惠式 AI 农技助手。

## 二、项目目标

- **多模态四分类**：精准区分真菌病害、虫害、土壤缺肥、农药药害四大类，细分为 23 类常见灾害
- **小样本泛化**：弱监督小样本学习 + 田间数据增强，少量样本即可训练高泛化模型
- **离线轻量化**：模型量化压缩，手机端无网络也能推理，适配农村弱网
- **AI 农事顾问**：农业垂直 RAG 知识库，输出用药、施肥、绿色减药、农事日历方案

## 三、系统架构

### 3.1 整体架构

```
┌─────────────────────────────────────────────────┐
│              前端（Vue3 + Element Plus）          │
│   拍照识别 / 结果可视化 / AI顾问 / 历史档案 / 农事日历  │
└───────────────────────┬─────────────────────────┘
                        │ HTTP / 静态资源
┌───────────────────────┴─────────────────────────┐
│            后端（FastAPI + SQLAlchemy）           │
│   识别接口 / RAG问答 / 历史管理 / 农事建议 / 系统状态  │
└───────┬───────────────────────────┬─────────────┘
        │                           │
┌───────┴───────┐         ┌─────────┴──────────┐
│  YOLOv8-lite  │         │   RAG 向量知识库    │
│  轻量化推理   │         │  FAISS + 句向量嵌入 │
│  + SAM 分割   │         │  + 农业知识 JSON    │
└───────────────┘         └────────────────────┘
```

### 3.2 技术选型

| 模块 | 技术 | 选型理由 |
|---|---|---|
| 前端 | Vue 3 + Vite + Pinia + Element Plus | Composition API、轻量、生态成熟 |
| 后端 | FastAPI + SQLAlchemy + SQLite | 异步高性能、零配置数据库、易部署 |
| 检测 | YOLOv8-lite + ONNX INT8 量化 | 精度速度均衡、CPU 友好、可离线 |
| 分割 | SAM / 超像素回退 | 小样本辅助提升病斑定位精度 |
| RAG | FAISS + sentence-transformers | 纯 CPU 向量检索、多语言嵌入、离线 |
| 数据增强 | OpenCV 自研管线 | 模拟田间遮挡/逆光/雨雾，小样本泛化 |

## 四、功能模块

### 4.1 智能识别诊断
- 拍照/上传作物叶片图片
- YOLOv8-lite 推理输出四大类 + 细分类别 + 置信度 + 检测框
- SAM/超像素分割细化病斑区域，提取颜色纹理特征辅助分类
- 自动判定危害程度（轻/中/重）

### 4.2 智能治理方案生成
- 根据识别类别 + 危害程度生成专属方案
- 推荐用药（名称、剂量、频次）
- 绿色减药替代方案（生物农药、物理防治）
- 缺肥对应元素补充建议
- 预防措施清单
- RAG 知识库检索补充针对性建议

### 4.3 AI 农事顾问（RAG）
- 自然语言问答
- 农业垂直知识库检索（病虫害/施肥/植保规范）
- 返回答案 + 知识来源 + 关联治理方案

### 4.4 诊断历史与地块档案
- 历史诊断记录列表与详情
- 按大类筛选、分页
- 地块档案管理（作物、面积、长势阶段）

### 4.5 农事日历
- 二十四节气农事要点
- 当前节气针对性建议
- 自定义农事提醒（优先级、完成状态）

## 五、数据集说明

系统内置数据集自动构建脚本（`algorithm/data_builder/build_dataset.py`），无需人工采集：

- 覆盖水稻、小麦、玉米、番茄、黄瓜、苹果、柑橘等作物
- 23 类细分类别（病害/虫害/缺肥/药害）
- 程序合成叶片背景 + 病斑纹理生成 + 田间数据增强
- 每类 30 张基础样本，增强后可达数百张
- 输出 YOLO 格式标注（images/ + labels/ + data.yaml）

真实场景中可混入少量真实样本提升精度，本脚本保证零样本即可跑通完整训练流程。

## 六、模型轻量化

- **通道剪枝**：YOLOv8n 宽度缩放至 0.25，参数量大幅减少
- **两阶段训练**：先冻结 backbone 微调检测头（防小样本过拟合），再全网络小学习率精调
- **ONNX 导出**：FP16 半精度，体积减半
- **INT8 动态量化**：体积再减 4 倍，CPU 推理提速 2-3 倍
- **离线推理**：onnxruntime CPUExecutionProvider，无任何云端依赖

## 七、应用价值

1. **普惠农技**：降低农技服务门槛，偏远地区农户也能获得专业诊断
2. **减药增效**：绿色方案引导减少化学农药使用，符合国家减药政策
3. **降本增收**：精准诊断减少误诊误治损失，测土配方施肥降低投入
4. **数据沉淀**：诊断记录与地块档案为精准农业积累数据资产
5. **可复制推广**：纯软件、0 硬件成本，易于在各地农技站、合作社部署
